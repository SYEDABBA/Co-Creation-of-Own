# 🚀 NeuroFocusSynth (YUGRAAL Invention)

## 🎯 Purpose
A futuristic neuro-acoustic soundscape synthesizer, focus timer, and generative audio-visual flow state environment powered by the Web Audio API.

## 🔥 Usefulness
Empowers creators, engineers, and students to enter deep flow states instantly with real-time synthesized binaural beats (Alpha, Theta, Delta, Gamma), solfeggio frequencies (432Hz, 528Hz), procedural noise generators (White, Pink, Brown), an interactive particle audio visualizer, and a lightweight micro-task tracker.
