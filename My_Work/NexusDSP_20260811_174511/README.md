# 🚀 NexusDSP (YUGRAAL Invention)

## 🎯 Purpose
A futuristic Web Audio Synthesizer, Dynamic Step Sequencer, and Real-Time Reactive Visualizer Canvas built with Web Audio API and HTML5 Canvas graphics.

## 🔥 Usefulness
Empowers creators, musicians, and visual enthusiasts to generate synthesize custom patches, construct rhythm loops, visualize external audio files or live microphone feeds in 4 breathtaking cyberpunk visualization modes, and analyze audio spectrums in real time.
